# Reglas del Proyecto CuboMind

1. **Sin Emojis**: Jamás incluir emojis en ningún archivo de código, documentación (Markdown) o mensajes.
2. **Lenguaje Claro y Directo**: No usar palabras rebuscadas ni tecnicismos innecesarios. Explicar todo de manera accesible para cualquier persona.
3. **Bases Algorítmicas Reales**: Explicar el funcionamiento del cubo de Rubik utilizando conceptos reales de algoritmos y ciencias de la computación (espacios de estados, búsqueda en grafos, descomposición en subproblemas, algoritmo de reducción, Kociemba y BFS), manteniendo la explicación comprensible para todos.
